Help
  1. Open the optical sender on the trusted computer.
  2. Press Start camera and keep its QR display inside the guide.
  3. Keep both devices still until receipt completes.
  4. Press Save encrypted capsule and move the file to a trusted computer.

Pause turns the camera off and keeps your progress. Resume camera continues the same transfer. Stop / reset clears all received bytes, including a completed capsule, so you can receive another transfer. The 15-minute transfer limit includes pauses. Keep this page visible to retain progress.

Camera frames stay on this device. The receiver never asks for a passphrase or opens the contents. A hosted build can still be replaced by its host. Installation and updates require a trusted HTTPS host; the displayed build identifier does not authenticate the code running on this device.
